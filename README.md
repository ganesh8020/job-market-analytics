# Job Market Analytics Dashboard

A full-stack web application that analyzes job market data and presents insights through an interactive dashboard with charts and metrics.

---

## Tech Stack

### Backend
- Java Spring Boot
- Spring Data JPA
- REST APIs
- H2 Database (in-memory for demo)
- Docker

### Frontend
- React.js
- Chart.js (react-chartjs-2)

---

##  Features

- ETL Pipeline:
  - Fetches job data from an external API
  - Stores data in database
-  Analytics Dashboard:
  - Average Salary calculation
  - Skill Demand (Bar Chart)
  - Skill Distribution (Pie Chart)
-  REST APIs for data access
-  Dockerized backend for easy deployment
